MR을 올리면
피아노 연습 게임이 돼요

찬양 MR(반주 음원)이나 녹음 파일을 올리면, 음을 자동으로 찾아서 떨어지는 건반과 피아노 타일로 바꿔 줘요. 태블릿·휴대폰은 화면을 누르고, PC는 키보드로, 전자피아노는 USB로 연결해서 연주해요.

🎵 MR·악보 파일 올리기 MR(mp3 · m4a · wav) · 악보(MusicXML) · MIDI · 연습 파일(.json)
1. 올리기MR을 올리면 음을 자동으로 찾아요. 악보(MusicXML)·MIDI는 더 정확하고 바로 열려요. 아래 샘플 곡으로 바로 시작해도 돼요.
2. 연습하기「건반」은 실제 피아노 자리 연습, 「타일」은 박자 게임이에요. 속도를 줄여서 시작해 보세요.
3. 나눠 주기「연습 파일 저장」으로 받은 파일을 아이들에게 보내면, 아이들은 변환 없이 바로 열어요.
